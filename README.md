# APM32E030_SDK
Official software development kit for Geehy APM32E030 microcontrollers.

## Current version

- SDK version: V1.0.3
- Supported device: APM32E030
- Official package date: July 3rd, 2025
- Release notes date: October 27th, 2026
- Official download: [APM32E030_SDK_V1.0.3.zip](https://www.geehy.com/uploads/tool/APM32E030_SDK_V1.0.3.zip)

## Supported development environments
The package includes projects and resources for Keil MDK, IAR Embedded Workbench, and Eclipse/GCC, together with CMSIS, peripheral libraries, middleware, board support, and examples.
